# Archive

## Purpose

The `archive/` directory contains retained historical or legacy project materials.

## Ownership

Archive ownership remains with architecture governance until content is removed, migrated, or formally retained.

## Responsibilities

- Preserve historical context where required.
- Avoid using archived code as active production source.
- Prevent archive content from becoming an undocumented dependency.

## Public Interfaces

Archived files expose no supported runtime or application interfaces.

## Dependencies

Active applications, services, and packages must not depend on archive content.
