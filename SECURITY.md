# Security Policy

## Purpose

Security is a platform capability for JUTH HOS. All security-sensitive work must follow the Constitution and approved ADRs.

## Reporting Security Issues

Report suspected vulnerabilities privately to the project owner or Chief Software Architect. Do not disclose security issues publicly before triage and remediation planning.

## Security Review Requirements

Security review is required for changes affecting:

- Authentication
- Authorization
- IAM policy evaluation
- Audit logging
- Secrets or environment configuration
- Patient or clinical data handling
- External integrations
