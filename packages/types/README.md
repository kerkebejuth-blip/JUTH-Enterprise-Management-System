# Types Package

## Purpose

The Types package contains shared TypeScript contracts.

## Ownership

Owned by platform engineering and architecture governance.

## Responsibilities

- Export shared compile-time contracts.
- Keep contracts explicit and versionable.
- Avoid adding business entities without approved sprint scope.

## Public Interfaces

Public exports are defined in `src/index.ts`.

## Dependencies

This package should remain dependency-light and framework-independent.
