# Utils Package

## Purpose

The Utils package is reserved for shared utility functions.

## Ownership

Owned by platform engineering.

## Responsibilities

- Provide reusable, framework-light utilities.
- Avoid duplicating package-specific logic.
- Participate in repository test gates without failing when no tests are configured.

## Public Interfaces

No public source interface is currently defined.

## Dependencies

Future dependencies should be avoided unless clearly justified.
