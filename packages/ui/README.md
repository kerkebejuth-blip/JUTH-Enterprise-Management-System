# UI Package

## Purpose

The UI package contains shared reusable interface components and design-system primitives.

## Ownership

Owned by frontend platform engineering.

## Responsibilities

- Provide reusable UI building blocks.
- Preserve accessibility and design-system consistency.
- Avoid module-specific business workflows.

## Public Interfaces

Public exports are defined in `src/index.ts`.

## Dependencies

This package declares runtime and peer dependencies required by exported components.
