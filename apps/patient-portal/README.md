# Patient Portal

## Purpose

The Patient Portal workspace is reserved for patient-facing application development.

## Ownership

Ownership is assigned through approved sprint plans and architecture governance.

## Responsibilities

- Remain isolated from staff-facing clinical workspace concerns.
- Avoid implementation until an approved sprint defines scope.
- Participate in root quality gates without failing when no tests are configured.

## Public Interfaces

No public runtime interface is currently defined.

## Dependencies

Future dependencies must follow workspace and Constitution standards.
