# Deployment Prompt Guidance

## Status

Version 1.0 Enterprise Architecture Baseline.

## Purpose

Deployment prompts shall avoid unapproved environment assumptions.

## Required Considerations

Deployment prompts must consider:

- CI quality gates.
- Configuration.
- Secrets.
- Health checks.
- Observability.
- Backup and recovery.
- Rollback.
- Release baseline.

## Restriction

Do not introduce production deployment assumptions without approval.
