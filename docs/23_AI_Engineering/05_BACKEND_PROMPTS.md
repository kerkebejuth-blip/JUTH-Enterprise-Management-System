# Backend Prompt Guidance

## Status

Version 1.0 Enterprise Architecture Baseline.

## Purpose

Backend prompts shall preserve NestJS, Clean Architecture, DDD, and modular monolith standards.

## Required Considerations

Backend prompts must consider:

- Module boundaries.
- Application services.
- Domain layer.
- Infrastructure adapters.
- DTOs.
- Validation.
- Guards.
- Interceptors.
- Exception handling.
- Tests.

## Restriction

Do not create clinical or business endpoints without approved Domain Blueprint and sprint scope.
