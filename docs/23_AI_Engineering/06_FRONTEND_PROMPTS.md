# Frontend Prompt Guidance

## Status

Version 1.0 Enterprise Architecture Baseline.

## Purpose

Frontend prompts shall preserve the Enterprise Workspace and shared design system.

## Required Considerations

Frontend prompts must consider:

- Enterprise Patient Workspace.
- Layout engine.
- Routing philosophy.
- Component boundaries.
- Accessibility.
- Responsive behavior.
- Performance.
- AI workspace integration.

## Restriction

Do not redesign layouts, routing, or clinical workflows without approval.
