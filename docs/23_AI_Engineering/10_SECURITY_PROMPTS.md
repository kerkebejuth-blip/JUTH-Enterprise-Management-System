# Security Prompt Guidance

## Status

Version 1.0 Enterprise Architecture Baseline.

## Purpose

Security prompts shall preserve confidentiality, integrity, availability, auditability, and fail-closed behavior.

## Required Checks

Security prompts must check:

- Authentication.
- Authorization.
- RBAC.
- PBAC.
- Claims.
- Sessions.
- JWT.
- Refresh tokens.
- Secrets.
- Encryption.
- Audit logging.
- Input validation.

## Rule

Security-sensitive changes require review before merge.
