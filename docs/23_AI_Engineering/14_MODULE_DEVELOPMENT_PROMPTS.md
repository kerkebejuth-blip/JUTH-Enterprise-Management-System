# Module Development Prompt Guidance

## Status

Version 1.0 Enterprise Architecture Baseline.

## Purpose

Module development prompts govern future bounded-context implementation.

## Required Inputs

Before module implementation, prompts must include:

- Approved Domain Blueprint.
- Sprint scope.
- Ubiquitous language.
- Aggregates.
- Commands.
- Queries.
- Repositories.
- Policies.
- Events.
- Security.
- Testing expectations.

## Rule

No bounded context may be implemented from prompt memory alone.
