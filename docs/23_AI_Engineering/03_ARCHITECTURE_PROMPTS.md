# Architecture Prompt Guidance

## Status

Version 1.0 Enterprise Architecture Baseline.

## Purpose

Architecture prompts guide analysis and documentation without permitting unapproved redesign.

## Architecture Prompt Requirements

Architecture prompts must ask for:

- Repository evidence.
- Constitution alignment.
- ADR impact.
- Dependency direction.
- Security impact.
- Operational impact.
- Required approvals.

## Governance

Any prompt that changes architecture requires ADR review before implementation.
