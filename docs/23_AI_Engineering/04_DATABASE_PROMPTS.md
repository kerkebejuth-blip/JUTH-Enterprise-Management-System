# Database Prompt Guidance

## Status

Version 1.0 Enterprise Architecture Baseline.

## Purpose

Database prompts shall preserve data architecture governance.

## Required Considerations

Prompts involving data must consider:

- Aggregate ownership.
- UUID strategy.
- Audit fields.
- Soft deletes.
- Versioning.
- Transactions.
- Migrations.
- Indexes.
- Multi-facility readiness.

## Restriction

No Prisma model, migration, or schema change may be generated without approved sprint scope and review.
