# API Prompt Guidance

## Status

Version 1.0 Enterprise Architecture Baseline.

## Purpose

API prompts shall preserve REST, versioning, DTO, validation, response envelope, and OpenAPI standards.

## Required Considerations

API prompts must include:

- API version.
- Request DTO.
- Response DTO.
- Validation.
- Error response.
- Authentication.
- Authorization.
- OpenAPI tags and operation IDs.

## Restriction

Do not expose database entities directly.
