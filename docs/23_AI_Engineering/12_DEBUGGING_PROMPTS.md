# Debugging Prompt Guidance

## Status

Version 1.0 Enterprise Architecture Baseline.

## Purpose

Debugging prompts shall investigate evidence before proposing fixes.

## Required Steps

Debugging shall:

1. Reproduce the issue.
2. Identify logs or failing commands.
3. Isolate the root cause.
4. Propose the smallest safe fix.
5. Run validation.
6. Document unresolved risk.

## Rule

Debugging must not become unapproved refactoring.
