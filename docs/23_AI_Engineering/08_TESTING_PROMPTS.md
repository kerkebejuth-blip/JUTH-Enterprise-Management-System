# Testing Prompt Guidance

## Status

Version 1.0 Enterprise Architecture Baseline.

## Purpose

Testing prompts shall create verifiable, non-invented validation plans and tests.

## Test Categories

Use testing prompts for:

- Unit tests.
- Integration tests.
- Contract tests.
- E2E tests.
- Security tests.
- Accessibility tests.
- Performance tests.
- Architecture validation.

## Rule

Tests must reflect real behavior and must not invent clinical business rules.
