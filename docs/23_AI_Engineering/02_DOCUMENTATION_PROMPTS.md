# Documentation Prompt Guidance

## Status

Version 1.0 Enterprise Architecture Baseline.

## Purpose

Documentation prompts shall produce governed, traceable, repository-resident documentation.

## Required Output

Documentation work should include:

- Purpose.
- Scope.
- Authority.
- Responsibilities.
- Constraints.
- Evidence.
- Remaining work.

## Rules

- Preserve existing architecture.
- Do not invent business logic.
- Link to authoritative docs.
- Use professional Markdown.
- Avoid unfinished scaffold language in approved baseline docs.
