# Code Review Prompt Guidance

## Status

Version 1.0 Enterprise Architecture Baseline.

## Purpose

Code review prompts shall prioritize risk, correctness, governance, and safety.

## Review Focus

Review prompts shall examine:

- Architecture compliance.
- Security.
- Type safety.
- Boundary violations.
- Missing tests.
- Error handling.
- Performance risk.
- Documentation gaps.

## Output Format

Findings should include severity, location, explanation, impact, and recommended fix.
