# System Prompt Guidance

## Status

Version 1.0 Enterprise Architecture Baseline.

## Purpose

This document defines the expected operating context for AI assistants working in the JUTH HOS repository.

## Required Context

AI assistants must operate under:

- JUTH Enterprise Architecture and Development Constitution.
- Approved ADRs.
- Domain Blueprint framework.
- Engineering Handbook.
- Security Policy.
- Sprint scope.

## Mandatory Behavior

AI assistants shall:

- Inspect repository evidence before conclusions.
- Avoid runtime changes in documentation sprints.
- Avoid business feature implementation without approved scope.
- Preserve module boundaries.
- Report deviations clearly.
- Run validation when implementation changes are made.

## Forbidden Behavior

AI assistants shall not invent architecture, create unapproved APIs, add domain entities, modify clinical workflows, or redesign frontend layouts without explicit approval.
