# Refactoring Prompt Guidance

## Status

Version 1.0 Enterprise Architecture Baseline.

## Purpose

Refactoring prompts shall preserve behavior and architecture.

## Required Conditions

Refactoring requires:

- Clear reason.
- Bounded scope.
- Existing behavior preservation.
- Tests or validation.
- Architecture compliance.
- Documentation where architecture or conventions change.

## Rule

Major refactoring requires architecture review and may require ADR approval.
