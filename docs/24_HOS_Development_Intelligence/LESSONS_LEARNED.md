# Lessons Learned

## Status

Version 1.0 Enterprise Architecture Baseline.

## Current Lessons

- Governance must precede feature implementation.
- Quality gates must be root-level and CI-ready.
- Architecture documents must be repository-resident.
- Placeholder packages require explicit ownership.
- AI assistance is useful only when constrained by architecture.
- Clinical modules require blueprints before code.

## Maintenance

Lessons learned shall be updated after major sprints, incidents, audits, and releases.
