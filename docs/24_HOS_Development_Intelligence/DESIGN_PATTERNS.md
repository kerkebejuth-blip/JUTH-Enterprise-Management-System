# Design Patterns

## Status

Version 1.0 Enterprise Architecture Baseline.

## Approved Patterns

JUTH HOS favors:

- Clean Architecture.
- Domain-Driven Design.
- Modular monolith.
- Repository Pattern.
- Unit of Work.
- Specification Pattern.
- DTO contracts.
- Event publication.
- Adapter and anti-corruption layers.
- Composition over inheritance.

## Pattern Governance

Patterns shall solve real complexity. Do not introduce abstractions for demonstration or premature generalization.
