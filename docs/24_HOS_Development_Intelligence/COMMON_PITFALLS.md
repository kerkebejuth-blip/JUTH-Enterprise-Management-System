# Common Pitfalls

## Status

Version 1.0 Enterprise Architecture Baseline.

## Pitfalls to Avoid

- Implementing clinical features without a Domain Blueprint.
- Putting business rules in controllers.
- Putting workflow rules in UI components.
- Exposing database entities through APIs.
- Bypassing authorization.
- Adding dependencies without ownership.
- Redesigning architecture during feature work.
- Treating AI output as approved architecture.
- Ignoring audit and historical record requirements.

## Response

When a pitfall is identified, stop implementation, document the risk, and escalate if architecture or clinical safety is affected.
