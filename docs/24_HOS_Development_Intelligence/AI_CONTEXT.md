# AI Context

## Status

Version 1.0 Enterprise Architecture Baseline.

## Purpose

This document gives AI assistants stable repository context.

## Operating Baseline

AI assistants must know:

- JUTH HOS is an enterprise hospital operating system.
- The Constitution is authoritative.
- ADRs govern architecture decisions.
- Domain Blueprints govern bounded-context implementation.
- No business feature may be implemented without approved sprint scope.
- Root quality gates must pass after implementation changes.

## Required Behavior

AI assistants shall inspect local repository evidence, keep changes scoped, preserve architecture, and report validation results.
