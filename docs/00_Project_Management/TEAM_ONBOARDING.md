# Team Onboarding

## Status

Version 1.0 Enterprise Governance Baseline.

## Purpose

This document defines onboarding expectations for JUTH HOS contributors.

## Required Reading

New contributors shall review:

- `README.md`
- `ARCHITECT_INSTRUCTIONS.md`
- Constitution volumes.
- ADRs.
- Engineering Handbook.
- Domain Blueprint framework.
- Security Policy.
- Contribution Guide.
- Architecture Compliance Matrix.

## Required Setup

Contributors shall verify:

- PNPM install works.
- Root quality gates run.
- Workspace structure is understood.
- Sprint scope is clear.
- Architecture constraints are understood.

## Contributor Expectations

Contributors shall:

- Work in approved scope.
- Preserve architecture.
- Avoid undocumented decisions.
- Update docs with code changes.
- Escalate security, clinical, or architecture risks.
