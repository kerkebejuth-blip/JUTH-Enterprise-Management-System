# ADR-002: PNPM Workspace Strategy

## Status

Approved

## Context

The platform requires deterministic workspace installs, explicit package boundaries, and efficient dependency management.

## Decision

JUTH HOS shall use PNPM workspaces with workspace roots defined for `apps/*`, `services/*`, and `packages/*`.

## Alternatives

- npm workspaces.
- Yarn workspaces.
- Independent package installation per workspace.

## Consequences

- Dependency installation is centralized and reproducible.
- Packages must declare their own dependencies explicitly.
- Root quality gates can operate across the whole workspace.
- Lockfile changes must be reviewed as part of dependency governance.
