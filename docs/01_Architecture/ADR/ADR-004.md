# ADR-004: React Frontend

## Status

Approved

## Context

The Staff Portal must provide a responsive enterprise clinical workspace with reusable components, shared state boundaries, and a modular frontend model.

## Decision

Frontend applications shall use React with TypeScript.

## Alternatives

- Angular.
- Vue.
- Server-rendered frontend only.
- Multiple frontend frameworks per specialty.

## Consequences

- Shared UI packages and design-system primitives can be reused across applications.
- Specialty modules shall extend the shared workspace rather than replace it.
- Component testing, accessibility validation, and type safety are required for mature frontend delivery.
