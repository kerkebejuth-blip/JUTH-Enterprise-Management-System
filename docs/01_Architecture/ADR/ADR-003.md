# ADR-003: NestJS Backend

## Status

Approved

## Context

The backend requires modular structure, dependency injection, API documentation readiness, validation, guards, interceptors, and enterprise service organization.

## Decision

Backend services shall use NestJS with TypeScript as the primary backend application framework.

## Alternatives

- Express without an application framework.
- Fastify-only application structure.
- A non-TypeScript backend framework.

## Consequences

- Modules, controllers, services, providers, guards, interceptors, pipes, and filters are first-class backend constructs.
- Backend architecture remains compatible with Clean Architecture and DDD boundaries.
- NestJS framework details must remain outside the domain model.
