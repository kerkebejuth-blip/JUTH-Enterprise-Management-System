# ADR-001: Monorepo Using Turborepo

## Status

Approved

## Context

JUTH HOS contains frontend applications, backend services, shared packages, documentation, and operational assets that must evolve together under enterprise governance.

## Decision

The repository shall use a monorepo managed with Turborepo for task orchestration across `apps/`, `services/`, and `packages/`.

## Alternatives

- Multiple independent repositories.
- A single repository without task orchestration.
- Early microservice repository separation.

## Consequences

- Shared quality gates can run consistently from the root.
- Cross-package changes are easier to review.
- Workspace boundaries must be actively governed to avoid coupling.
- Turbo configuration becomes part of the engineering baseline.
